# Bee-Link visual identity

The approved logo is the open layout: a bee towing an Ultra Bee-style electric motorcycle, with BEE-LINK below. Use `assets/bee-link-logo.png` for project documentation and `app/dist/assets/bee-link-logo.png` for the dashboard. This is a raster concept, not a vector master or an official Surron mark.

- Yellow: `#FFD400`; black: `#111111` (logo artwork uses black).
- Use black text on yellow; never white text on yellow. Use neutral light surfaces for dense telemetry.
- Use yellow for active navigation, primary actions, chart traces and brand accents.
- Preserve explicit simulated, live, replay, missing and stale labels. Colour alone must never establish signal confidence.
- Keep the logo proportions and clear space; do not crop or stretch it.
- Hexagons can be supporting accents; the approved main logo has no border. Keep patterns away from charts and readings.

The offline preview embeds its logo so it still works as a single HTML file. Run `python tools/build_preview.py` after changing dashboard assets.
